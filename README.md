# Пятница

Репозиторий содержит исходники приложения. Локальные модели, Python-окружения, готовая сборка, записи микрофона, история разговоров и параметры авторизации в Git не включены. На новом компьютере сначала установите зависимости и скачайте модели по инструкциям ниже; установленная копия на исходном ПК продолжает работать самостоятельно.

Персональный голосовой помощник для Windows. Готовая версия установлена в этой папке. Для работы не нужны аккаунты, ключи API или интернет.

**Версия 1.6.3:** устойчивее нажатия по изображению, восстановление состояния свёрнутых окон, резервный захват видимого окна, номера дисплеев Windows и локальный список открытых программ. Безопасные UIA-нажатия выполняются без подтверждения; личный текст исключён из debug-логов. Сохранены текущая архитектура, локальная Qwen 3.5 4B и голосовое управление. [Примеры, диагностика и ограничения](docs/DESKTOP.md).

Сохранены функции версии 1.5: упрощённый интерфейс и интерактивное ядро — наведите курсор или потяните шар мышью. Сохранены локальные голоса, активация «Пятница» при свёрнутом окне, каталог из 90 действий и 1453 формулировок, четыре стиля и выбор микрофона. Все команды — в [COMMANDS.md](COMMANDS.md), изменения — в `CHANGELOG.md`.

## Запуск

Дважды нажмите ярлык **«Пятница»** на рабочем столе или в этой папке. Также можно запустить `release/Friday-win32-x64/Friday.exe`.

Приложение автоматически запускает локальный сервис и при необходимости Ollama. При первом включении холодная загрузка модели может занять до 1–2 минут; состояние видно в «Настройки → Система». Следующие ответы значительно быстрее. Не переносите отдельно EXE: ему нужны остальные файлы проекта.

## Общение

- Напишите сообщение и нажмите **Enter**. **Shift+Enter** добавляет новую строку.
- Нажмите кнопку микрофона или **Ctrl+Пробел** и произнесите команду. Запись отправится после 1,5 секунды тишины; повторное нажатие завершает её вручную.
- **Голосовая активация:** скажите «Пятница, открой проводник». Или скажите «Пятница», дождитесь короткого сигнала и произнесите команду. Ожидание команды заканчивается после 8 секунд тишины. После ответа помощница снова ждёт имя. Функция включена по умолчанию; управляется в «Настройки → Активация голосом».
- Можно свернуть окно: микрофон и обработка команд продолжают работать. Полный выход из приложения останавливает прослушивание. Компьютер должен быть включён и не находиться в режиме сна.
- **Esc** останавливает запись, ответ, озвучку и выключает голосовую активацию. Чтобы вернуть её, включите переключатель в настройках. «Отмена» после обращения отменяет только текущую команду.
- **«Свободный разговор»** включает микрофон после каждого ответа без повторения имени. На это время ожидание слова «Пятница» приостанавливается.
- В «Настройки → Голос и микрофон» можно выбрать устройство, проверить микрофон и настроить голосовую активацию. Проверка не отправляет речь в чат.
- В настройках доступны три выразительных голоса Qwen3-TTS и три быстрых голоса Silero, скорость речи и автоматическая отправка после паузы.
- Система должна разрешать доступ классических приложений к микрофону в настройках конфиденциальности Windows.

Максимальная запись — 2 минуты. Горячие клавиши работают, когда окно Пятницы активно. Подробные текстовые ответы можно прослушать повторно кнопкой динамика под сообщением.

Ядро вращается перетаскиванием мышью и реагирует на приближение курсора. После фокусировки на ядре стрелки меняют поворот, пробел ставит движение на паузу. Кнопка паузы есть и рядом с шаром. В «Настройки → Оформление» доступны цветовая тема и три режима анимации. «Только чат» скрывает ядро в разговоре. Переключатели озвучки и свободного разговора находятся под полем сообщения.

## Команды

Во вкладке «Команды» выберите категорию или найдите действие по любой его формулировке. Кнопка «Формулировки» раскрывает все варианты. Нажатие на фразу подставляет её в чат; «Выполнить» запускает указанное действие. Для команд с параметрами «Ввести команду» оставляет место для вашего текста или числа.

Примеры: «Пятница, не могла бы ты открыть калькулятор», «Перейди к настройкам звука», «Установи громкость на пятидесяти процентах», «Вычисли двадцать пять умножить на четыре», «Прочитай мои заметки». Выполняется одна команда за сообщение; вопросы-инструкции и отрицания не запускают действия. Падежи поддерживаются в опубликованных вариантах; произвольные имена файлов не преобразуются в другие слова.

| Скажите или напишите | Результат |
| --- | --- |
| «Открой калькулятор» | Запускает калькулятор Windows |
| «Открой блокнот» | Запускает блокнот |
| «Открой проводник» | Открывает проводник |
| «Который час?» | Показывает и произносит время |
| «Какая сегодня дата?» | Сообщает дату |
| «Состояние системы» | Загрузка CPU и оперативной памяти |
| «Запиши заметку: купить чай» | Сохраняет заметку во вкладке «Мои заметки» |

Во вкладке «Команды» доступны 90 базовых действий с поиском: запуск программ, папки, звук, музыка, окна, скриншоты и информация о компьютере. Также можно попросить найти файл по имени, открыть сайт или результаты веб-поиска, создать папку на рабочем столе. Примеры приведены в `CHANGELOG.md`.

Остальные сообщения обрабатывает локальная Qwen 3.5. Она может объяснять интерфейс и составлять план из разрешённых инструментов; программа проверяет и выполняет каждый шаг. Произвольный код не исполняется. Необратимые нажатия, ввод и клавиши требуют подтверждения. Подробнее — в [описании управления компьютером](docs/DESKTOP.md).

## Локальные модели

- **Qwen 3.5 4B Q4_K_M** через Ollama — диалог, планирование и понимание изображений. Установлена; в настройках доступны для выбора и загрузки 0.8B, 2B и 9B.
- **Whisper Large v3 Turbo** — с версии 1.6.1 распознавание русского языка на GPU в INT8/FP16. При недоступной CUDA используется та же модель на CPU INT8. После распознавания видеопамять освобождается для диалога и озвучки. В настройках голоса доступна «Проверка распознавания» с прослушиванием записи без выполнения команды.
- **Vosk Small RU 0.22** — локальное распознавание обращения на CPU. Поток хранится только в ограниченном буфере памяти; окружающая речь не сохраняется в историю и на диск.
- **Qwen3-TTS 0.6B CustomVoice** — выразительные женские голоса Serena, Sohee и Ono Anna, ускоренный расчёт через Faster Qwen3-TTS / CUDA Graphs в отдельном процессе. Модель загружается при первом ответе. Образцы тембров подготовлены заранее. Длинные ответы озвучиваются по предложениям.
- **Silero v4 RU** — быстрые женские голоса Xenia, Baya и Kseniya, 48 кГц, расчёт на CPU.

Все модели и библиотеки скачаны. Никаких облачных голосов или браузерного SpeechRecognition приложение не использует. Это собственная интерпретация персонажа; голос не копирует актрису из фильма.

Проверка на этом компьютере: трёхсекундная русская фраза распознана приблизительно за 0,6 с; первый токен прежней Qwen3 — за 0,55 с; синтез ответа Silero после прогрева — около 0,7 с. В версии 1.4.1 образцы Qwen3-TTS начинали играть за 0,14–0,19 с, новые короткие ответы после прогрева — приблизительно за 2 с. Первый ответ с загрузкой модели и прогревом занял 23 с. До исправления тестовая фраза готовилась 89 с. Это измерения конкретных примеров; длина ответа и текущая загрузка системы влияют на время.

Если ответ отображается без звука, проверьте переключатель «Озвучивать ответы». В настройках видны этап и время подготовки. «Остановить» и смена тембра отменяют текущий синтез, не оставляя его в очереди. При недоступном голосе выводится ошибка вместо неограниченного ожидания.

## Хранение и обслуживание

- `data/friday.db` — разговоры и заметки (SQLite).
- `models/` — Whisper, Vosk, Silero и Qwen3-TTS.
- `.venv-tts/` — отдельная среда выразительных голосов; `data/qwen-voice.log` — её журнал.
- `data/voice-previews/` — готовые образцы трёх выразительных голосов; для восстановления выполните `.venv/Scripts/python.exe scripts/prepare_voice_previews.py`. Ответы из разговоров здесь не сохраняются.
- `%USERPROFILE%/.ollama/models` — Qwen.
- `data/backend.log` — журнал локального сервиса.
- `data/runtime.json` — временные параметры локального соединения, не публикуйте его.
- Настройки голоса и микрофона хранятся в локальном профиле Electron.

Сервис слушает только `127.0.0.1:17835`. Запросы защищены случайным токеном и проверкой источника. Во время разговора приложение обращается только к локальным адресам. Записи микрофона не сохраняются в историю; сохраняются распознанный текст и ответы. Подключённая ранее Ollama управляет собственными обновлениями независимо от Пятницы.

При ошибке загрузки модели откройте «Настройки» и нажмите кнопку обновления в блоке моделей — она повторит неудавшуюся загрузку. При проблемах с микрофоном выберите правильное устройство ввода и проверьте разрешения Windows.

## Разработка

### Сообщения в Telegram Desktop

«Напиши Насте привет», «Отправь Насте сообщение я задержусь», «Ответь Насте, что я занят»,
«В телеге напиши Насте привет», «Напиши в Telegram @username: позвони мне» — отдельный локальный
сценарий, без Qwen и Bot API. Падежи имён разбирает установленный словарь pymorphy3.

Пятница открывает Telegram, ищет чат через UI Automation, проверяет заголовок и идентичность
истории, набирает черновик и показывает точный текст. Отправка происходит только по кнопке
**«Отправить сообщение»**. **«Нет»**, голосовое **«отмена»** во время подтверждения и **«Пятница, стоп»**
останавливают сценарий. Для голосовой отмены должна быть включена голосовая активация.
Существующий черновик не перезаписывается. При отмене очищается только неизменённый черновик,
набранный самой Пятницей, в том же чате; после смены чата или ручного редактирования он остаётся.

«Напиши Насте» → «Что написать Насте?» → «Я задержусь на час» работает в рамках одного разговора.
«Ответь ей, что буду позже» использует последний проверенный чат. Если нашлось несколько людей,
нужно уточнить полное имя или @username. Имя пользователя проверяется в отдельном поле профиля,
после чего оно используется для повторного поиска этого контакта. Контекст хранится в памяти 10 минут.

Успех подтверждает новое точное сообщение в истории Telegram и статус исходящего сообщения;
это не гарантия прочтения адресатом. При неопределённом результате автоматической повторной
отправки нет. Текст сообщений, значения полей и имена контактов не попадают в debug-логи;
обычная история разговора с Пятницей по-прежнему хранится локально.

Нужен Telegram Desktop с доступными полями UI Automation (проверены русские подписи).
Если идентичность получателя или история недоступны, отправка останавливается. Кнопки вызываются
через UIA Invoke, при его отсутствии — Legacy Accessibility; для «Избранного» есть стандартная
клавиша Ctrl+0 с проверкой фокуса. Vision и координаты для отправки не используются: они не дают
надёжной проверки получателя. Глобальные результаты, которые Telegram не раскрывает как чаты,
могут потребовать сначала добавить контакт или открыть с ним диалог вручную.

Проверка реального Telegram без отправок: `.venv/Scripts/python.exe tests/telegram_windows_integration.py`.
Дополнительный флаг `--send-self` явно разрешает одну тестовую отправку в собственное «Избранное».

### Сборка и проверки

Стек: Electron, React, TypeScript, Vite; Python 3.11, FastAPI, SQLite; Ollama, Faster Whisper, PyTorch.

```powershell
npm install
node node_modules/electron/install.js
npm run build
npm start
```

Python-окружение `.venv` уже установлено. Для восстановления: `python -m venv .venv`, установка `backend/requirements.txt`, затем CPU-сборки `torch==2.8.0` из `https://download.pytorch.org/whl/cpu` и пакетов из `backend/requirements-gpu.txt`. Скрипт `.venv/Scripts/python.exe scripts/download_models.py` восстанавливает основные модели; нужна работающая Ollama. Модель голосовой активации восстанавливается командой `.venv/Scripts/python.exe scripts/setup_wake.py`.

`npm run package` пересобирает Windows-приложение; после изменения Python или фронтенда достаточно `npm run build` и перезапуска. Изменения Electron требуют пересборки EXE.

Проверки:

```powershell
.venv/Scripts/python.exe -m pytest tests/test_backend.py -q
.venv/Scripts/python.exe -m pytest tests/test_pc.py -q
.venv/Scripts/python.exe -m pytest tests/test_command_language.py -q
.venv/Scripts/python.exe -m pytest tests/test_expressive_voice.py tests/test_wake_word.py -q
.venv/Scripts/python.exe tests/integration.py
node tests/ui.cjs
node tests/microphone.cjs
node tests/electron.cjs
node tests/upgrade-ui.cjs
node tests/catalog-ui.cjs
node tests/wake-ui.cjs
node tests/wake-minimized.cjs
node tests/voice-upgrade.cjs
node tests/voice-regression.cjs
node tests/voice-native.cjs
node tests/refinement-ui.cjs
```

Интеграционные проверки требуют запущенного локального сервиса. Проверки интерфейса используют установленный Edge; проверка микрофона подаёт синтетическую запись, не записывает окружающие звуки. UI-тесты создают тестовую историю и заметку.

`voice-regression.cjs` сам поднимает временный сервис на порту 17840, проверяет три образца, озвученные команды, содержимое записей через Whisper и отмену синтеза. `voice-native.cjs` проверяет готовый EXE с отдельным профилем и временной базой; перед ним закройте Пятницу. Он также проверяет озвучку при свёрнутом окне.

Источники и лицензии перечислены в `THIRD_PARTY.md`.
