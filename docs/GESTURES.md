# Камера и жесты

Во вкладке **Камера и жесты** включите превью, выберите ведущую руку и нужное окно, затем нажмите **Включить управление**. Вторая рука не нужна для разрешения действий; обе руки получают скелет. Превью зеркальное, движение вправо в превью означает вправо на мониторе.

Сначала раскройте ладонь на четверть секунды. Распознаватель не принимает уже удерживаемый щипок сразу после включения или возвращения руки в кадр.

| Режим | Жест одной ведущей рукой | Действие |
|---|---|---|
| Окна | Соединить большой и указательный пальцы, удержать 0,22 с и двигать руку | Перемещение выбранного окна; разжать пальцы — отпустить |
| Окна | Указательный и средний пальцы буквой V, 0,9 с | Развернуть / восстановить |
| Окна | Открытая ладонь 0,3 с, затем движение в сторону | Перенести окно на соседний монитор в этой стороне |
| Видео | Щипок 0,55 с | Пауза / продолжить |
| Видео | Открытая ладонь 0,3 с, затем движение в сторону | Вперёд / назад на 5 секунд |
| Любой | Кулак на 1 с | Выключить управление |

Двигайте открытую ладонь примерно на четверть ширины кадра за 0,85 с. Между командами отпускайте жест. Для щипка оставляйте остальные пальцы расправленными, чтобы отличать его от кулака. Доступна левая или правая ведущая рука. При плохом освещении, пересечении рук, низкой уверенности и потере руки действие прекращается.

Esc во вкладке, кнопка остановки и «Пятница, стоп» выключают управление. Голосовая остановка требует включённого голосового пробуждения, как и раньше. Новая голосовая/текстовая команда также отключает жесты, чтобы два исполнителя не меняли одно окно одновременно. При смене вкладки или сворачивании Пятницы камера выключается. Повторное включение управления всегда явное.

## Локальная реализация

- `src/CameraHands.tsx`: камера по выбору, lifecycle, preview, управление сессией; камера открывается только по кнопке, без микрофона.
- `src/hands.worker.ts`: MediaPipe Hand Landmarker 1.0.1, CPU/WASM в Worker, 21 точка на каждой из двух рук; один кадр в обработке, разрешение детектора до 640 px, превью до 1280×720.
- `src/gestures.ts`: классификация поз, выдержка, сглаживание, гистерезис щипка, блокировка повторов и сброс при потере/скачке руки. Веб-камера не отправляется в Qwen/Codex.
- `src/handSkeleton.ts`: тонкие светящиеся кости, суставы, полупрозрачная ладонь и дуга удержания жеста. Можно выключить скелет.
- `backend/gesture_control.py`: закрытый набор действий, привязка к HWND/PID/времени создания процесса, токен сессии и последовательность пакетов. Перемещение через SetWindowPos, без удерживаемых кнопок мыши. Положение проверяется. Разворачивание и перенос переиспользуют desktop_native.window_action. Номера мониторов Windows сохранены; сосед определяется по физическому расположению.
- `backend/gesture_media.py`: Windows GlobalSystemMediaTransportControlsSession; выбирается конкретная медиасессия, а не случайное активное окно. Успех подтверждается состоянием воспроизведения/позицией.
- Сервер отключает сессию после 1,8 с без heartbeat; незавершённая медиаоперация отменяется по «стоп». Движения не накапливаются в очереди.

Никакие кадры, landmarks или видео не пишутся на диск. В backend отправляются только разрешённое действие и нормированные координаты ведущей руки. При выключенной камере модель не загружается. Облачные ключи и сеть для работы не нужны.

`npm install` устанавливает пакет, `npm run build` / `npm run dev` автоматически готовят WASM и модель в `public/hand-tracking/`. Первая подготовка скачивает модель Google (7,5 МБ), сверяет SHA-256, дальнейшие сборки используют локальную копию. Папка не хранится в Git. Для Python зависимости указаны в `backend/requirements.txt`.

## Проверка

```powershell
$env:PYTHONUTF8='1'
.\.venv\Scripts\python.exe -m pytest -q
node tests/gestures.cjs
.\.venv\Scripts\python.exe tests/gesture_windows_integration.py
node tests/camera-ui.cjs
node tests/gesture_media_integration.cjs
node tests/camera_device_integration.cjs
```

`camera-ui.cjs` загружает официальный тестовый кадр `right_hands.jpg` в `data/` при его отсутствии. Проверяет реальную модель и Worker, две руки, отсутствие внешних запросов при работе, запуск управления, Esc, endpoint голосовой остановки, закрытие камеры и отказ разрешения. Это синтетический видеопоток из тестового изображения, а не проверка точности живых жестов пользователя.

Windows integration использует только временное Win32-окно; проверяет движение, размеры и перенос на реальный соседний монитор. Media integration создаёт свою тихую аудиосессию в отдельном Edge, проверяет паузу, воспроизведение и ±5 секунд. Пользовательские плееры и чаты тесты не трогают.

`camera_device_integration.cjs` отдельно включает настоящую камеру в Electron с временным профилем, проверяет живой поток и освобождение устройства при сворачивании. Восстановление окна само камеру не включает. Кадры не сохраняются. На машине разработки проверен поток 1280×720, около 15 обработанных кадров/с и 55 мс на кадр; живых рук в кадре во время проверки не было. Точность жестов конкретного пользователя при его освещении нужно оценить руками у камеры.

## Ограничения

Это управление окнами и медиаплеером, не полноценная замена мыши: нет кликов по произвольным кнопкам, выбора текста или отправки сообщений жестами. Перемещение внутри дисплея ограничено его рабочей областью; на другой дисплей используется отдельный жест ладонью. Нельзя перенести окно дальше крайнего монитора. Приложение с повышенными правами может отклонить действие Windows.

Плеер должен публиковать медиасессию Windows и разрешать seek. Некоторые сайты, Telegram-видео, реклама и прямые эфиры не поддерживают перемотку; в таком случае выводится ошибка и управление останавливается. Клавиши в произвольное окно не посылаются. После ошибки выберите цель и включите управление заново.

Источники: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js), [правило handedness для незеркального входа](https://github.com/google-ai-edge/mediapipe/blob/master/docs/solutions/hands.md), [Windows media sessions](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession).
