# Friday Voice Recorder

Небольшая Windows-утилита для записи датасета голоса **Пятницы**.

В проект уже встроен текущий корпус из **970 фраз** (`TR-0001` … `TR-0970`). Программа показывает по одной фразе, записывает отдельный WAV и автоматически собирает `metadata.csv` для актуального `piper1-gpl`.

## Самый простой запуск на Windows

1. Установи **Python 3.11 или 3.12 x64** с python.org. При установке отметь **Add Python to PATH**.
2. Запусти `install.bat` один раз.
3. После установки запускай `run.bat`.

## Как записывать

1. Выбери микрофон.
2. Нажми `Запись` или клавишу **Space**.
3. Прочитай только текст фразы. ID `TR-xxxx` произносить не нужно.
4. Снова нажми **Space** или `Стоп`.
5. Запись автоматически сохранится в `dataset/wav/` и, если включён автопереход, откроется следующая фраза.
6. Кнопкой `Прослушать` можно проверить запись, а `Перезаписать` — заменить её.

Горячие клавиши:
- `Space` — запись / стоп
- `←` и `→` — предыдущая / следующая фраза
- `Ctrl+P` — прослушать текущую запись

## Что создаётся

```text
dataset/
├── wav/
│   ├── TR-0001.wav
│   ├── TR-0002.wav
│   └── ...
├── metadata.csv
└── session.json
```

Каждый WAV сохраняется как:
- mono
- PCM 16-bit
- 22050 Hz

Если микрофон не умеет писать непосредственно в 22050 Hz, программа пишет в поддерживаемой частоте и автоматически пересэмплирует результат в 22050 Hz.

`metadata.csv` выглядит так:

```text
TR-0001.wav|Текст первой фразы.
TR-0002.wav|Текст второй фразы.
```

Это соответствует текущему формату обучения `piper1-gpl`: имя аудиофайла + `|` + текст.

## Контроль качества

После записи программа проверяет:
- длительность;
- пиковый уровень;
- RMS-громкость;
- клиппинг;
- слишком тихую запись.

В начале и конце автоматически сохраняется небольшое поле тишины. Нормализация громкости специально **не применяется**, чтобы не портить исходный датасет.

Рекомендуемый уровень: обычная речь примерно `-24 … -14 dBFS RMS`, пики лучше держать ниже `-3 dBFS`.

## Папка датасета

По умолчанию используется папка `dataset` рядом с программой. Кнопкой **Папка датасета** можно выбрать другую папку. Состояние сессии сохраняется автоматически, поэтому после перезапуска можно продолжить с того же места.

## Сборка EXE

После `install.bat` запусти:

```text
build_exe.bat
```

PyInstaller соберёт Windows-приложение в:

```text
dist/FridayVoiceRecorder/FridayVoiceRecorder.exe
```

Лучше использовать папочную сборку PyInstaller, а не `--onefile`: так запуск быстрее и меньше проблем с аудио-библиотеками.

## Важные советы для записи

- Один микрофон на весь датасет.
- Не менять расстояние до микрофона между сессиями.
- Не включать музыку, Discord-шумодав и агрессивные AI-фильтры.
- Не записывать с сильным эхом комнаты.
- Если оговорилась — перезаписать всю текущую строку.
- Не читать ID `TR-xxxx`.
- Лучше делать перерывы каждые 20–30 минут, чтобы голос не менялся от усталости.
